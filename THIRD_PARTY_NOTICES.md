# Sources and attribution

This project uses public processed data, configuration, annotation and original
numerical routines from [EngreitzLab/CRISPR_comparison](https://github.com/EngreitzLab/CRISPR_comparison),
commit `50587422e6b11259ead6fbc6f867681c788f39b7`. Original upstream numerical
functions are executed unchanged. The Python translation, analyses and interface
are separate, AI-assisted work prepared by Cathy Liu. No affiliation or endorsement
by the Engreitz Lab or Stanford is implied.

The benchmark combines published experiments; their original reference labels are
retained on every row. See the pinned upstream
[data documentation](https://github.com/EngreitzLab/CRISPR_comparison/blob/50587422e6b11259ead6fbc6f867681c788f39b7/resources/crispr_data/README.md)
for source literature and processing. Main methodological background:
[Fulco et al., 2019, Activity-by-contact model of enhancer–promoter regulation from thousands of CRISPR perturbations](https://doi.org/10.1038/s41588-019-0538-0).
The lab's [resources page](https://www.engreitzlab.org/resources/) provides broader
context and newer methods; this project evaluates only the saved example.

Original sources retain their attribution and applicable rights. This project's
license does not relicense third-party data or software. The upstream repository
license is reproduced below.
